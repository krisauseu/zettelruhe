# Lizenz: AGPL-3.0 für den öffentlichen Stand

Zettelruhe wird als Open-Source-Projekt unter **AGPL-3.0** veröffentlicht (bis zum ersten Public Launch darf das Repo vorübergehend ohne final gesetzte Lizenzdatei laufen, die Ziel-Lizenz ist aber AGPL-3.0). Begründung: Self-hosted-first (ADR-0001) — Copyleft erschwert Closed-SaaS-Rebrands ohne Rückfluss; bewusster Trade-off gegen maximal permissive Adoption (MIT/Apache).
